# 小鸡回家吃饭 · 可玩原型

按策划文档实现的 10 关可玩原型。纯前端，零依赖。

## 运行

直接双击 `index.html`（或拖进浏览器）即可。

如需本地服务器：

```bash
cd /workspace/chick-game
python3 -m http.server 8765
# 打开 http://localhost:8765/index.html
```

## 操作

| 操作 | 手势 |
|---|---|
| 移动 | 点击地面；按住拖动可持续引导 |
| 跳上石台 | 点击高处的平台 |
| 拾取 / 邀请 / 开闸 / 启动 / 转镜子 | 点它即可——**不用走到跟前**，小鸡会自动走过去完成 |
| 只是走路 | 点地面（按住拖动可持续引导） |
| 发射激光 | **按住**底部红色按钮（桌面端也可按住空格） |
| 暂停 / 重玩 | 右上角 ❚❚ 按钮 |
| 返回 | 左上角 ‹ 返回（桌面端 Esc） |

**防卡关**：第 1 关全程有手指引导；其他关卡静止超过 22 秒也会出现引导指
针，指向当前该去的地方（第 3/6/8/10 关不会直接指门，避免剧透谜题答案）。

激光按住越久越强：**一档（细）→ 二档（粗，破木门）→ 三档（全功率，破铁门）**。
电量条见右上，松开自动回充。

## 目录

```
index.html      页面结构
style.css       界面样式
js/levels.js    10 关关卡数据（改关卡只动这个文件）
js/render.js    程序化绘图（无图片素材）
js/game.js      玩法核心：移动、光线步进、破门、伙伴
js/ui.js        菜单 / 关卡 / 结算 / 图鉴 / 存档
js/audio.js     WebAudio 合成音效（无音频文件）
js/main.js      输入与适配
```

## 关卡一览

| 关 | 新机制 |
|---|---|
| 1 回家吃饭 | 移动、拾取、按键、二档破木门 |
| 2 两道门 | 电量管理 |
| 3 镜子反射 | 光路折射 |
| 4 被卡住的伙伴 | 一档光烧断绳子 |
| 5 铁门与晚饭 | 三档持续照射 |
| 6 高处的门 | 站上石台改变发射高度 |
| 7 双装置 | 两束光同时命中，6 秒窗口 |
| 8 光路迷宫 | 三面镜子接力 + 干扰镜 |
| 9 断电危机 | 电闸恢复回充速率 |
| 10 全家吃饭 | 综合关 + 团圆结局分支 |

进度、星级、伙伴收集存于 localStorage（键 `chick_dinner_save_v1`）。
